# Open Logic Project (Portuguese)

This is the Portuguese (pt-BR) translation of the content files of the
[Open Logic Project](https://openlogicproject.org/) by Pedro Lima.

To compile you first have to install the [main
repository](https://github.com/OpenLogicProject/OpenLogic). Once that
is done, there is a subdirectory `locale`. Change into this
subdirectory and clone this repository:
```
$ cd locale
$ git clone git@github.com:OpenLogicProject/OpenLogic-pt.git pt
```
(Note the `pt` at the end is necessary to clone into the directory
`locale/pt/`.)

You can then compile the files in the resulting directory
`locale/pt/`, e.g.,
```
$ cd pt
$ pdflatex open-logic-complete
```

## Textbooks (`courses/`)

This repository also contains complete Portuguese editions of Open Logic
textbooks, under `courses/`:

- `courses/sets-logic-computation/` — _Conjuntos, Lógica, Computação_
  (translated and adapted by Pedro Lima)
- `courses/set-theory/` — _Teoria dos Conjuntos_ (translated and adapted
  by Pedro Lima)

Each course has its own `README.md` with full build instructions. In short:
clone the English `OpenLogic` repo, clone this repo into its `locale/pt`,
clone the `photos` and `portraits` assets into `OpenLogic/assets/`, install
the gitinfo2 hooks (see `githooks/`), then run `make` inside the course
directory.

## Git hooks (credits page)

The credits page of each book shows the Git revision and date through the
`gitinfo2` package. Copy the hooks in `githooks/` into `.git/hooks/` so that
`.git/gitHeadInfo.gin` is generated automatically on commit/checkout —
otherwise the credits page shows `revisão (None)` / `unknown`. See
[`githooks/README.md`](githooks/README.md). The per-course `olprevision.tex`
is generated by `make` (via `misc/makeolprevision`) and is not versioned.

## Process reports (`relatórios/`)

`relatórios/` documents the translation process of the _Sets, Logic,
Computation_ book — planning, audits, terminology decisions and fix logs —
in Portuguese, for the next translator. Start at
[`relatórios/README.md`](relatórios/README.md).

The requirements for localizing (translating) the Open Logic Project
are described in
[`locale/LOCALIZATION.md`](https://github.com/OpenLogicProject/OpenLogic/blob/master/locale/LOCALIZATION.md)

The Open Logic Project is an open source, open access collection of
materials on advanced logic, aimed mainly at philosophers, but also
suitable for computer scientists and mathematicians. The text can be
rearranged and remixed. You can produce custom textbooks from it, so
they take the aim of the course and the preferences of the instructor
into account. It is written in LaTeX.

For more information, see the <a
href="https://openlogicproject.org/">project website</a> and <a
href="https://github.com/OpenLogicProject/OpenLogic/wiki">Open Logic
wiki</a>.

This repository contains LaTeX source files only. Head to the <a
href="https://builds.openlogicproject.org/">builds site to download PDFs</a>.
