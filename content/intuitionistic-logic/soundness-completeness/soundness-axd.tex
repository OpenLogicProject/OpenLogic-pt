\olsection{Correção das \usetoken{P}{derivation} axiomáticas}

\begin{editorial}
  A prova de correção depende do fato de que todos os axiomas são
  intuicionisticamente válidos; isso ainda precisa ser provado, p.ex., no capítulo de semântica.
\end{editorial}

\begin{thm}[Correção]
  \ollabel{thm:soundness}
  Se $\Gamma \Proves !A$, então $ \Gamma \Entails !A$.
\end{thm}

\begin{proof}
  Provamos que, se $\Gamma \Proves !A$, então $\Gamma \Entails !A$.
  A prova é por indução sobre o número~$n$ de !!{formula}s na
  !!{derivation} de~$!A$ a partir de~$\Gamma$. Mostramos que, se
  $!A_1$, \dots, $!A_n = !A$ é !!a{derivation} a partir de~$\Gamma$,
  então $\Gamma \Entails !A_n$. Observe que, se $!A_1$, \dots,
  $!A_n$ é !!a{derivation}, então $!A_1$, \dots, $!A_k$ também é, para
  todo $k<n$.

  Não há !!{derivation}s de comprimento~$0$; portanto, para $n=0$, a
  afirmação vale vacuamente. Suponha, então, que ela valha para todas
  as !!{derivation}s de comprimento~$<n$. Distinguimos casos conforme
  a justificativa de~$!A_n$.
  
  \begin{enumerate}
  \item $!A_n$ é um axioma. Todos os axiomas são válidos; portanto,
    $\Gamma \Entails !A_n$ para todo~$\Gamma$.
  \item $!A_n \in \Gamma$. Então, para quaisquer $\mModel{M}$ e $w$,
    se $\mSat{M}{\Gamma}[w]$, evidentemente
    $\mSat{M}{\Gamma}{!A_n}[w]$, O.s.\@, $\Gamma \Entails !A$.
  \item $!A_n$ decorre por \MP{} de $!A_i$ e
    $!A_j \ident !A_i \lif !A_n$. $!A_1$, \dots, $!A_i$ e $!A_1$,
    \dots, $!A_j$ são !!{derivation}s a partir de~$\Gamma$; portanto,
    pela hipótese de indução, $\Gamma \Entails !A_i$ e
    $\Gamma \Entails !A_i \lif !A_n$.
    
    Suponha $\mSat{M}{\Gamma}[w]$. Como $\mSat{M}{\Gamma}[w]$ e
    $\Gamma \Entails !A_i \lif !A_n$, temos $\mSat{M}{!A_i \lif
      !A_n}[w]$. Por definição, isso significa que, para todo $w'$ tal
    que $Rww'$, se $\mSat{M}{!A_i}[w']$, então
    $\mSat{M}{!A_n}[w']$. Como $R$ é reflexiva, $w$ está entre os $w'$
    tais que $Rww'$, O.s.\@, se $\mSat{M}{!A_i}[w]$, então
    $\mSat{M}{!A_n}[w]$. Como $\Gamma \Entails !A_i$,
    $\mSat{M}{!A_i}[w]$. Logo, $\mSat{M}{!A_n}[w]$, como queríamos
    mostrar.
  \end{enumerate}
\end{proof}
